# 雨停之前的約定 · 原創聲音設計

## 交付與來源

- `runtime/`：遊戲用 stereo 44.1 kHz Vorbis OGG，適合 Godot。
- `source/`：stereo 44.1 kHz / 16-bit PCM WAV 原檔。
- `generate_audio.py`：完整作曲事件、音色與音效合成程式；固定亂數種子，可再生。
- `manifest.json`：素材相對路徑、識別碼、BPM、調性、時長、循環屬性、SHA-256 與量測。
- `validation.json`：實際 OGG 解碼後的數值檢驗。
- `validate_audio.py`：可重跑的交付檢查程式。

全部旋律、節奏、和聲配置與聲音由程式原創製作。沒有下載錄音、現成音樂、取樣包、聲音字型，沒有模仿特定藝人或複製既有歌曲。NumPy/SciPy 用於 DSP，FFmpeg 的 Vorbis 編碼器只負責格式轉換。成品不含聲音字型或第三方音樂素材，因此沒有第三方素材署名或取樣授權要求。可隨本遊戲使用、剪輯與重新混音；不對特定司法管轄區的生成內容著作權地位作保證。

## 配樂

### music_city · Window Lights

- 84 BPM，D major，24 小節，68.571 秒。
- A 8 小節 → B 8 小節 → A′ 8 小節。
- 溫柔電鋼琴主旋律，錯落的中聲部鍵盤、立體聲柔和 pad、低音，以及低音鼓、木質節拍、刷奏高頻。
- A 的上行轉折與留白對應城市行走；B 抬高旋律與鐘音回答；再現收回 D 音與主和弦。
- 主要和聲：Dmaj7 → Bm7 → Gmaj7 → A → F#m7 → Bm7 → Em(add9) → A；尾段回 Dmaj7。
- 適用：雨季城市、展場準備、一般日常推進。

### music_warm · Two Cups, Still Warm

- 76 BPM，F major，24 小節，75.789 秒。
- A 8 小節 → B 8 小節 → A′ 8 小節。
- 柔氈鋼琴分解和弦、舒緩延音旋律、極輕刷奏與木質聲、B 段與再現的高音鐘音點綴。
- A 的延伸三度和較長旋律音像不急著結束的談話；B 由 Bb 出發，最後回 Fmaj7。
- 主要和聲：Fmaj7 → Dm(add9) → Gm7 → C7 → Am7 → Bbmaj7 → Gm7 → C7。
- 適用：咖啡店、陶藝空間、建立信任的親近對話。

### music_reflection · After the Last Train

- 64 BPM，B minor，20 小節，75 秒。
- A 8 小節 → B 4 小節 → A′ 8 小節。
- 低中音柔氈琴、低音延音與較濃柔和 pad；無鼓點。B 段以稀疏鐘音回答旋律。
- 旋律使用長音與空白，中央 4 小節短橋段不刻意推高潮；以 B minor 的 add9 色彩保留雨夜餘韻。
- 主要和聲：Bm(add9) → Gmaj7 → Dmaj7 → Asus2 → Em(add9) → Bm(add9) → Gmaj7 → F#sus4。
- 適用：夜班結束、天文館安靜片段、選擇前的回望。

### music_ending · The Sky Keeps Its Promise

- 92 BPM，A major，24 小節，62.609 秒。
- A 8 小節 → B 8 小節 → A′ 8 小節。
- 穩定八分音符柔氈琴、上行抒情主題、低音、輕木質節奏與細小鼓點；B 段與再現加入明亮鐘音層。
- 四首中最開闊、最明亮的旋律音域，最後明確回 A 主音與 Amaj9。
- 主要和聲：Amaj9 → F#m(add9) → Dmaj7 → E(add9) → C#m7 → F#m(add9) → Bm7 → Amaj9。
- 適用：展覽完成、關係的積極回應與片尾。

## 環境與音效

- `ambience_rain`：32 秒 stereo 循環。週期性頻域濾波白噪音、緩慢週期性強弱與柔和非音高雨滴；沒有外來現場錄音。左右聲道不同，避免像固定單點噴氣聲。
- `sfx_page`：0.48 秒紙張翻動，寬頻濾波噪音與摩擦包絡。
- `sfx_camera`：0.35 秒低音量雙段機械快門與短促回捲聲。木質短脈衝構成，無槍械／爆炸錄音。
- `sfx_ui`：0.16 秒圓潤木質確認聲。

## Godot 整合

1. 僅將 `runtime/*.ogg` 複製至遊戲音訊資產資料夾；WAV 不必加入發行版。
2. 四首配樂與雨景在 OGG 匯入設定打開 Loop，三個 SFX 關閉 Loop。OGG 的 LOOPSTART / LOOPEND 是附加資訊；不要只依賴自動辨識。
3. 配樂起點是完整小節。所有音符尾音與房間反射以環形方式疊加，原 WAV 首末樣本一致；不使用把整首壓成淡入淡出的「假循環」。
4. 場景換曲建議 0.8–1.4 秒 crossfade，避免對話中切斷延音。
5. 建議 Music bus 先設 -10 至 -14 dB，再依 UI 與使用者音量測試；Rain bus 先設 -16 至 -20 dB。SFX bus -6 至 -10 dB，按鍵音可更小。
6. 配樂源峰值 -4.44 dBFS，保留疊加餘裕；同時播放兩首 crossfade 仍應避免 bus 超限。建議使用等功率 crossfade 或將總線再保留 3 dB 餘裕。
7. 不用真實樂器音源，這是柔和的合成鍵盤配樂。畫面寫實不代表素材宣稱現場演奏或錄製。

## 品質檢查與限制

四個配樂有各自調性、旋律、和聲、BPM、節奏與 A/B/再現安排，不是同一段音樂更改速度。程式合成包含 8 個非純正弦衰減泛音、柔氈錘頭噪音、電鋼琴 FM 分量、失諧 pad、低音、鐘音、木質與刷奏打擊層。

已檢查 WAV／OGG 時長、stereo 44.1 kHz、有限數值、無 clipping、4 倍 oversampling true peak、循環首末樣本差、資產 SHA-256。壓縮格式可造成非常小的首末樣本差；具體數值見 `validation.json`。

重要：沒有透過耳機、喇叭或可辨識音訊的工具完成聽覺試聽。數值檢驗不等同音樂性、疲勞度或環境聽感檢验。正式發行前應在遊戲中完整聽一輪，特別檢查每首循環點、雨景音量與快門是否過尖。manifest 的 `listened` 明確為 false。
