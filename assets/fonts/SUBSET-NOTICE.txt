This modified font retains every supported Unicode character used by the complete
story, choices, collectible descriptions, ending descriptions, interface and fixed
error messages, plus printable ASCII. The game has no user-entered text fields.
No required character was omitted. Glyph outlines were not changed.

The modified family and PostScript/CFF names are renamed to
Rain Promises CJK Subset / RainPromisesCJKSubset-Regular.
This avoids using any original primary or reserved font name for the derivative.
The original complete font is retained at provenance/font/NotoSansCJKtc.otf.
